# MineCMS · Demo

Публичный сайт на Next.js 16 + Tailwind v4 + shadcn/ui + Motion. Данные — по HTTP через `@minecms/sdk`.

```bash
cp .env.example .env
pnpm install
pnpm dev
```

ENV: `NEXT_PUBLIC_CMS_URL` (по умолчанию `http://localhost:3333`), `NEXT_PUBLIC_STUDIO_URL` (по умолчанию `http://localhost:3333/admin`).
